# Web Application

Next.js, React and TypeScript client for school administrators, teachers and online examination workflows.

Initial screens:
- authentication and school onboarding;
- school dashboard;
- academic setup;
- learning-material repository;
- AI question-generation workspace;
- question bank and exam builder;
- student exam portal;
- results and analytics.

All authorization and business rules must be enforced by the backend. The web client is not a trusted security boundary.
