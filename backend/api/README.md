# FastAPI Backend

This directory will contain the Python API application.

Planned modules:
- identity and school tenancy;
- academic structure and user management;
- document upload and processing jobs;
- approved content retrieval;
- AI question generation and validation;
- diagram specifications and assets;
- question bank and exam lifecycle;
- grading, results and synchronization.

Implementation starts with a typed FastAPI application, configuration management, health endpoint, database migrations and automated tests. Keep secrets in environment variables; never commit real credentials.
